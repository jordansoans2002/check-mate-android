# ✅ Check Mate

**Check Mate** is an Android app designed for Right Ship inspectors to conduct structured ship preparedness inspections. Inspectors work through a predefined questionnaire and fill out a detailed checklist — capturing responses, comments, actions taken, and photo evidence — then export the completed inspection as a professional PDF report.

---

## Features

- **Questionnaire-driven checklists** — Checklists are generated from a structured set of ship preparedness questions
- **Per-item response options** — Select from predefined options for each checklist item
- **Comments & actions** — Add free-text comments and document actions taken for each item
- **Photo attachments** — Attach images directly to individual checklist items as evidence
- **PDF export** — Export the completed checklist as a formatted PDF report including all responses, comments, actions, and images

## Download & Install

> **Note:** Check Mate is distributed as an APK directly from GitHub Releases. You will need to allow installation from unknown sources on your Android device.

### Step 1 — Allow Unknown Sources

Before installing, enable installation from unknown sources on your device:

1. Open **Settings** on your Android device
2. Go to **Apps** (or **Apps & Notifications**)
3. Tap **Special app access** → **Install unknown apps**
4. Select your browser or file manager and toggle **Allow from this source**

> On some devices this prompt appears automatically when you open the APK.

### Step 2 — Download the APK

1. Go to the [**Releases**](../../releases) page of this repository
2. Under the latest release (**v1.0.0**), find the **Assets** section
3. Tap or click **CheckMate-v1.0.0.apk** to download it

### Step 3 — Install

1. Once downloaded, open the APK file from your **Downloads** folder or notification tray
2. Tap **Install** when prompted
3. Tap **Open** once installation completes

## Requirements

- Android 8.0 (Oreo) or later
- Storage permission (required for saving PDFs and attaching images)

---

## Usage

1. Launch **Check Mate**
2. Start a new inspection — the app will load the ship preparedness questionnaire
3. For each checklist item:
    - Select the appropriate **response option**
    - Add any **comments** relevant to the finding
    - Record the **action taken**
    - Attach **photos** as supporting evidence (optional)
4. Once the inspection is complete, tap **Export** to generate a PDF report
